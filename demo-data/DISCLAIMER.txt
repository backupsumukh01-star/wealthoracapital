DISCLAIMER — DEMO / BACKTEST DATASET ONLY
==========================================

This folder contains a synthetic three-year demonstration and backtest dataset
generated for UI presentation, design reviews, and stakeholder walkthroughs of
the Meridian FX / Growzy fund management product.

IMPORTANT:

1. This data is FABRICATED. It is not live trading history, not audited
   performance, and not an offer to invest.

2. Past performance — including simulated or illustrative performance — does
   not guarantee future results. Capital is at risk.

3. Do NOT import these files into a production database without an explicit,
   reviewed migration plan. Prefer reading exports offline or via a dedicated
   demo environment.

4. Monthly return figures in this dataset are deliberately concentrated in an
   illustrative 5–10% range for presentation charts. They are not forecasts.

5. CSV, JSON, SQL, Prisma seed artefacts, HTML, and PDF reports under
   `3-year-backtest/export/` are regenerated by
   `node demo-data/3-year-backtest/generate.mjs` from the repository root.
